# 外部模型放置说明

把下载好的 **.glb** 模型按下表命名放到本目录，刷新页面即可自动替换对应的程序化版本（删除文件则自动回退）：

| 文件名 | 用途 | 建议 |
| :--- | :--- | :--- |
| `pavilion.glb` | 主仙山亭台 | 台阶朝向不对时调 `src/config/models.ts` 的 `yaw`；自带台基更佳 |
| `bridge.glb` | 悬空石桥 | 长轴沿模型 X 轴；会被自动拉伸到两岛之间并随坡度倾斜 |
| `pine.glb` | 迎客松 | 每座岛会摆放多棵 |
| `peach_tree.glb` | 桃花树 | 同上 |

- 模型会被自动：底面落地、水平居中、缩放到 `config/models.ts` 里的目标尺寸，无需在建模软件里调整比例。
- 面数建议：亭台 ≤ 5 万面，树 ≤ 1 万面（树会重复出现十几次）。
- 带发光材质（灯笼）的模型会自动提高自发光以触发泛光。
- 使用 CC-BY 授权的模型请在发布视频时标注作者。
- 如果 glb 使用 Draco 压缩，首次加载需联网获取解码器。
